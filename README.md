# シンプル動画プレイヤー (Windows / Python + PySide6)

最小限のローカル動画再生アプリです。外部 VLC / FFmpeg の手動インストールは不要です。
PySide6 に同梱の FFmpeg バックエンド (`ffmpegmediaplugin.dll` + `avcodec-63` 等) で再生します。

## 動作環境

- Windows 10/11 (64bit)
- Python 3.11 (3.11.9で検証)
- 依存は `requirements.txt` に固定 (`requirements-lock.txt` は実測freeze)
- 外部VLC・FFmpegの手動インストール不要 (PySide6同梱のFFmpegを使用)

## セットアップ

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

## 起動

```bat
run.bat
rem 動画を指定して起動:
run.bat C:\path\to\movie.mp4
```

または:

```bat
.venv\Scripts\python.exe main.py
```

## 使い方 (日本語UI)

- 「開く」ボタン / ファイルメニュー / ドラッグ&ドロップで動画を開く
- **フォルダをドラッグ&ドロップすると、中の動画 (再帰・隠しフォルダ除く・名前順・500件まで)
  をまとめてプレイリストに追加し、先頭を再生**。`.srt` 単体のドロップは字幕として読み込み
- 再生 / 一時停止 / 停止ボタン
- シークバーで位置移動、時間表示 `現在 / 全体`
- `←` / `→` で 5秒戻し / 5秒送り。ウィンドウ全体で効くため、どこにフォーカスが
  あっても操作できます (シークバーはフォーカスを取らない設定です)
- 音量スライダー + ミュート。映像の上でマウスホイールを回すと音量を 5 ずつ調整
- 全画面ボタン / F11 / ダブルクリックで切替、Esc で解除
- 全画面では一定時間マウス操作が無いと操作系とカーソルが自動で隠れ、
  マウスを動かすと再表示されます
- 再生終了・非対応ファイル・破損ファイルはダイアログ表示し、クラッシュしない
- 再生速度ボタンで 0.5 / 1.0 / 1.5 / 2.0倍速を切替
- 字幕 (.srt) 表示: 「字幕」ボタン / ファイルメニュー「字幕を開く...」で読み込み。
  動画と同じフォルダに同名 `.srt` があれば自動で読み込みます。「字幕 ON/OFF」で切替。
  「字幕」メニューからサイズ (小/中/大)、位置 (下/中央/上)、縁取り ON/OFF、背景帯 ON/OFF、
  文字色 (白/黒/黄/水色/緑/ピンク)、フォント (既定/游ゴシック UI/メイリオ/MS ゴシック/Segoe UI)
  を変更できます。縁取り色は文字色の輝度から自動で決まります (黒文字なら白縁)
- 字幕の文字コードは自動判定します (BOM 付き UTF-8 / UTF-8 / Shift_JIS/CP932)。
  「字幕」→「文字コード」で手動指定も可能です (指定が合わない場合は自動判定に戻します)
- プレイリスト: 「リスト」ボタン / ファイルメニュー「プレイリストに追加...」で登録。
  ダブルクリックで再生、前へ/次へで移動、動画終了時は次の動画へ自動送り (連続再生)
- プレイリストはドラッグで並べ替え可能。パネルの「上へ」「下へ」でも1つずつ移動でき、
  並び順は終了時に保存され次回復元されます
- A-B リピート: 再生中に **A** で開始点、**B** で終了点を決めると、その区間だけを
  繰り返し再生します (**C** で解除)。設定中は操作系に `A-B ループ 00:10 → 00:20` のように
  表示されます。A を押し直すと開始点を打ち直してループを解除します。
  一時停止中は位置を戻さず、B の先へシークすると A 側へ戻ります。
  終端に B を置いても停止せず A へ戻って続きます。A-B はファイル単位の設定で、
  別の動画を開くと解除されます (保存はしません)
- スクリーンショット: **Ctrl+S** で表示中のフレームを PNG として保存します
  (再生中でも一時停止中でも可。動画と同じフォルダに「動画名_日時.png」。
  同じ秒に続けて保存したときは連番を付けます)。「ファイル」→
  「スクリーンショットを名前を付けて保存...」で保存先を選べます。
  保存すると操作系に保存先が数秒表示されます
- フレーム送り: **`,` / `.`** で 1 フレームずつ戻る / 進む。再生中に押した場合は
  一時停止してから移動します (30fps の動画なら 33ms ずつ。fps が取得できない
  動画では約 30fps 相当で動きます)。先頭・終端では動きません
- プロパティ: 「ファイル」→「プロパティ...」で解像度・フレームレート・
  ビットレート・長さ・ファイルサイズを確認できます。コーデックや HDR は
  取得できた場合だけ表示します (取得できない項目は黙って省きます)
- 前回再生位置を記憶し、次回オープン時に自動再開（`resume.json`、上限100件。
  明示停止・視聴完了後は先頭から。範囲外・破損時は無視）
- 音量・ミュート・再生速度・プレイリスト・字幕表示設定 (表示ON/OFF、サイズ/位置/縁取り/文字コード/文字色/フォント/背景帯)
  を終了時に保存し、次回起動時に復元（`session.json`。破損・不在時は既定値）

## キーボードショートカット

アプリ内でも「ヘルプ」→「ショートカット一覧」(または **F1**) で確認できます。

| キー | 動作 |
|---|---|
| Space | 再生 / 一時停止 |
| ← / → | 5秒戻し / 5秒送り (ウィンドウ全体で有効) |
| ↑ / ↓ | 音量 ±10 |
| F | 全画面切替 (Escで解除) |
| M | ミュート切替 |
| S | 字幕 ON / OFF |
| A / B | A-B リピートの A 点 / B 点を設定 |
| C | A-B リピートを解除 |
| ] / [ | 再生速度 上げる / 下げる |
| , / . | 1 フレーム戻る / 進む (再生中は一時停止してから) |
| Ctrl+← / Ctrl+→ | 前の動画 / 次の動画 |
| Ctrl+S | 現在のフレームを PNG 保存 (動画と同じフォルダ) |
| F1 | ショートカット一覧を表示 |

## 対応形式 (FFmpeg依存)

mp4 (H.264/AAC 推奨), mkv, avi, mov, webm, wmv 等。
Qt 6.12 時点で Windows でも FFmpeg が標準バックエンドです。

## 配布用exe (Python不要)

Python 環境のない PC でも動く単体フォルダを生成できます。

```bat
build_exe.bat
rem 生成物: dist\mplayer\mplayer.exe (ポータブルフォルダ, 約150MB)
```

- PyInstaller でビルドし、QtMultimedia の ffmpeg プラグインと同梱 FFmpeg DLL
  (`avcodec-63` 等) を含めます
- ビルド後に自己診断 (`--selftest`) を自動実行し、実際にデコードできるか検証します
- アプリアイコン (`assets/app.ico`) と exe のバージョン情報も埋め込まれます
  (バージョンは `main.py` の `__version__` から自動生成)
- 手動診断: `dist\mplayer\mplayer.exe --selftest <動画> --selftest-out <結果.json>`
  (終了コード 0=成功, 1=失敗)

## Windows インストーラ

スタートメニュー登録・アンインストーラ付きのセットアップを作成できます。
[Inno Setup 6](https://jrsoftware.org/isinfo.php) が必要です。

```bat
build_installer.bat
rem 生成物: dist\installer\mplayer-setup-<version>.exe
rem ISCC.exe が見つからない場合は INNO_SETUP 環境変数で指定できます
```

- インストール先は既定でユーザー領域 (`%LOCALAPPDATA%\Programs`) のため管理者権限不要
- 日本語 UI、デスクトップショートカット (任意)、インストール直後の起動オプション付き

## 自動テスト (無音・無人で実行)

```bat
rem ワンコマンド検証 (venv作成〜全テスト):
check.bat
rem 直接実行・特定ステージ・詳細表示:
.venv\Scripts\python.exe tests\run_all.py
.venv\Scripts\python.exe tests\run_all.py p1b_seek
.venv\Scripts\python.exe tests\run_all.py -v
```

- 全ステージPASSを確認済み (詳細は `test_logs/summary.txt`)
- テスト中は音量0にするため音は出ません。製品の既定音量 (80) は変更しません
- 長時間再生の安定性も検証します (反復シーク・連続再生の自動送り・ウィンドウ生成破棄
  を繰り返した際のハンドル/RSS増加が小さいこと: `p19_stability`)
- 詳細ログは `test_logs/` に保存されます

## リリース / 変更履歴

- バージョンは `main.py` の `__version__` と `CHANGELOG.md` で管理します
- `v*` タグを push すると CI が exe とインストーラをビルドし、zip と
  `mplayer-setup-<ver>.exe` を添付した GitHub Release を自動作成します

```bat
git tag v1.0.0
git push origin v1.0.0
```

## トラブルシュート

- 映像が出ない: ` .venv\Lib\site-packages\PySide6\plugins\multimedia\ffmpegmediaplugin.dll` の有無を確認
- 音が出ない: OS の音量ミキサーとアプリ内ミュートを確認
- コーデック不足 (例: HEVC 等): H.264/AAC の mp4 に変換して利用
